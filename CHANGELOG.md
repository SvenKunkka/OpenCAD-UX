# Changelog

All notable changes to OpenCAD UX are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning follows
[SemVer](https://semver.org/).

## [0.1.0] - 2026-09-09 (MVP)

### Added
- Installable FreeCAD Python workbench "Product Design (OpenCAD UX)"
  (Init.py / InitGui.py / package.xml, GPL-3.0-or-later).
- Ribbon UI fully driven by `resources/ribbon.json`: 7 groups / 53 buttons
  (Sketch, Constraints, Create, Modify, Combine, Inspect, Insert/Export).
- Original flat icon set: 61 SVG glyphs × light/dark, generated by
  `scripts/make_icons.py` (no third-party/proprietary assets).
- Original light & dark themes with live apply + previous-stylesheet restore.
- Command catalogue with version-ordered native-id candidates and python
  fallbacks (`opencad_ux.commands.adapters`).
- Bilingual command search (EN + 中文, fuzzy/substring), recents boost,
  context filtering, `S` hotkey.
- Context actions: selection-aware panel (dock) + `Q` popup menu.
- Keymap subsystem: JSON presets, per-platform conflict detection
  (Ctrl vs ⌘), import/export, overlay dispatcher that never rewrites
  FreeCAD's own shortcuts.
- Navigation presets: probes for a native Fusion style, falls back to the
  closest built-in (Revit) through FreeCAD's `NavigationStyle` parameter,
  with python/native difference documentation.
- Reference-image workflow on `Image::ImagePlane`: import, attach to
  XY/XZ/YZ, quick width calibration, two-point calibration math, opacity,
  lock/hide, order hint.
- Unified Settings dialog (appearance/ribbon/navigation/shortcuts/workflow/
  system) with config-file backup & restore, layout reset, debug logging,
  "check updates".
- Safe command runner: friendly error messages for every failure path incl.
  no-document / nothing-selected / missing-command / API-limited actions
  (Move Face, Offset Face documented as unavailable on stock FreeCAD).
- Example models (real, parametric, generated & saved as .FCStd, STEP/STL
  exported): keyboard shell, mouse concept shell, enclosure with screw
  bosses + USB opening.
- Tests: 36 pure-python unit tests; 25 FreeCAD-console integration tests;
  in-GUI self-test command writing a JSON report + screenshot.
- Tooling: `scripts/run_pure_tests.sh`, `scripts/run_console_tests.sh`,
  `scripts/run_examples.sh`, `scripts/check_static.sh`,
  `scripts/install.sh`, `scripts/uninstall.sh`, `scripts/make_zip.sh`.
- Docs: README (EN/ZH), CONTRIBUTING, SECURITY, development notes,
  license/attribution notes, issue templates, GitHub Actions CI.

### Known limitations (also in README)
- Fusion-style Move Face / Offset Face unavailable via stock public API.
- PartDesign fillet/thickness *feature* objects need GUI face/edge picks;
  examples use equivalent OCC shape operations headlessly.
- Mouse-button remapping and Press/Pull direct manipulation not possible
  from python on stock FreeCAD; Revit fallback applied.
